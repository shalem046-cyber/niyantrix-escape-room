# NIYANTRIX'26 — Broken Web Escape Room

NIYANTRIX is a technical web-based escape room where the website itself becomes the puzzle.

## Run
Open the published GitHub Pages site to play the escape room. The game can still run without cloud configuration, but session records stay in that browser only.

For teams on different devices to appear together in the Admin Portal, configure the shared Supabase database by following [SUPABASE_SETUP.md](SUPABASE_SETUP.md). Do not put a Supabase service-role/secret key into this public repository.

## Game
- Session: 16 minutes
- Wrong answer penalty: 12 seconds
- System trace hint penalty: 30 seconds
- Five non-linear technical modules
- Final phrase: LOOK BEYOND THE BROKEN PAGE

## Modules
Signal Drift · Source Trace · Dead Packet · Logic Gate · Route Table
